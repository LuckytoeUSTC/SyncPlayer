# SyncPlayer

[English](README.md) · 简体中文 · [繁體中文](README.zh-Hant.md)

在一台 Windows 电脑或局域网内同步多个 PotPlayer 窗口，跟随绝对位置、播放状态和速度。每个窗口可设置偏移和静音，支持自动发现设备、连接确认和延迟显示。

**[下载 Windows x64 版本](https://github.com/LuckytoeUSTC/SyncPlayer/releases/latest)**：解压 ZIP，双击 `SyncPlayer.exe`。不需要另装 .NET；PotPlayer 需自行安装，视频需放在各台电脑上。

## 0. 快速入门

首次启动默认英语。点击右上角齿轮，直接选择 **简体中文** 切换语言，立即生效并自动保存。问号图标打开当前语言的说明书。

### 0.0 同一台电脑

1. 在 PotPlayer 中打开视频，多个视频分别在不同窗口打开。
2. 双击 `SyncPlayer.exe`，选择主窗口。
3. 打开主窗口下方的“本地同步”开关，在表格勾选需要“跟随”的窗口。
4. 在主窗口播放、暂停、跳转或调速。需要重新校准时点“对齐”。

只保留一个声音时，在其他窗口所在行勾选“静音”。视频起点有差别时，填写该行的“偏移(秒)”。

### 0.1 两台电脑

1. 两台电脑各自打开视频及 SyncPlayer，连接同一个局域网。
2. 两端都打开“远程连接”，控制端选另一台电脑，选择“我控制对方”，点“连接”。
3. 另一台电脑看到请求后点“接受”。
4. 控制端在窗口表中勾选对方电脑下面的视频窗口。
5. 操作控制端主窗口。只做跨电脑同步时，关闭“本地同步”即可。

搜索不到时，在另一台电脑打开“远程连接”并点“复制地址”，贴到控制端的“对方地址”，再点“连接”。无需查 IP 或填写端口。

## 1. 窗口表怎样使用

先列本机窗口，再按设备名称列远程窗口。主窗口始终是来源，不显示跟随复选框。名称以视频文件名为准，不显示播放器后缀；同一设备上的文件名相同时才加序号。长名称换行，悬停可看完整名称。新增、关闭和更换视频后自动刷新，也可以点击顶部环形箭头刷新。新发现的本机窗口默认不勾选。

| 项目 | 操作 |
| --- | --- |
| 主窗口 | 顶部选择操作来源。本机跟随窗口可以一个也不选。 |
| 跟随 | 勾选需要同步的窗口。本地同步关闭时隐藏本机其它窗口并停止操作，开启后恢复原选择。远程窗口需开启远程连接、获准连接且方向允许本机控制。 |
| 偏移(秒) | 留空或只输入空格会自动变为 `0`。可填正数、负数、小数，例如 `0.25`、`-1.5`。主窗口也可设置偏移。回车或点击其它位置提交，左右箭头每次调整 0.1 秒。 |
| 静音 | 只关闭这一窗口的声音，取消勾选恢复声音。与是否跟随无关；静音主窗口不影响其他窗口。 |
| 状态 | 显示窗口角色或连接状态。远程分组行还显示网络往返延迟。 |

偏移表示“此窗口位置 = 主窗口位置 + 此窗口偏移 − 主窗口偏移”。同一画面在主视频第 10 秒、另一视频第 12 秒出现，就给另一视频填 `2`；填 `-2` 则让它位于主窗口之前 2 秒。修改已勾选窗口的偏移会对齐；未勾选时仅保存本次设置。目标位置越过片头时停在第一帧等待；越过片尾时暂停在片尾附近的可定位画面，避免播放器自动重播或进入下一项。重新进入有效范围后自动恢复同步，回退或修改偏移也能恢复。片尾预留约 300 毫秒的解码保护区；此时跟随窗口暂停而主窗口继续播放是有意的边界行为。


修改主窗口偏移，会按偏移变化量移动主窗口；目标未越过视频边界时，其它窗口保持原位置。位置受视频头尾限制。下方跳转输入框的左右箭头同样每次调整 0.1 秒。
远程偏移和静音由有控制权的一端修改。播放器中的静音变化会随状态更新。偏移和跟随选择不跨程序重启保存。

## 2. 播放与跳转

| 控件 | 用途 |
| --- | --- |
| 三角形／双竖线按钮 | 同一个按钮随主窗口状态切换：三角形表示开始播放，双竖线表示暂停。操作主窗口、选中的本机窗口及有控制权的远程窗口。重复暂停不会切换为播放。 |
| 对齐 | 按主窗口当前绝对时间、速度和状态重新对齐，保留各窗口偏移。 |
| 本地同步开关 | 位于主窗口下方。默认开启；关闭后本机其它窗口从列表消失，停止向它们发送播放、对齐或跳转操作，选择保留。远程同步独立。 |
| 跳转 | 在独立区域输入从视频开始计算的秒数，例如 `90.5`，再点“跳转”。 |
| 问号图标 | 打开当前语言的说明书。图标悬停显示用途。 |
| 齿轮图标（设置） | 齿轮下方显示 English、简体中文、繁體中文，点选立即切换并自动保存，无需确认。设备名称、窗口选择和同步不因语言切换重置。 |

左右键、Ctrl 加左右键、进度条跳转及 X/C 调速，按播放器实际产生的位置和倍率处理，不假定快捷键跳转固定秒数。跟随窗口中的操作不会反向改变主窗口。

同机跳转会等待定位后恢复播放，解码起步差在这次操作内通过短暂调速处理。正常播放不做周期性补跳；调速直接同步倍率，并在这次变速后按需短暂微调跟随窗口的倍率，消除残留时间差，不跳转。本机目标约 100 毫秒，实际效果受解码和机器负载影响。

初次同步会检查精确跳转，必要时临时关闭“只跳到关键帧”。正常退出恢复程序修改过的选项。准备期间可能短暂改变画面，随后恢复并对齐；强制结束进程无法保证恢复。

## 3. 连接设备

“远程连接”开关与“本地同步”位于同一行，默认关闭。打开后显示连接区域；关闭后断开远程连接、停止远程控制并隐藏远程行。连接前两台电脑都需打开此开关。

- 本机名称：直接修改，按回车或移开焦点保存。默认形如 `PC-7K3M2Q`，根据本机信息生成，通常每台电脑不同。自定义名称保存在当前用户设置中。同名设备加四位短标识，连接按内部身份区分。
- 本机地址：自动获取 IP 并分配端口。“复制地址”复制选中的完整地址。多个网卡列出多个地址，有网关的连接优先。
- 设备列表：自动搜索同一局域网中的 SyncPlayer，逐台显示名称、连接标记及往返延迟。选中后点连接。可同时连接多台，选择另一台不会断开已有连接；断开按钮只作用于当前选中的设备。
- 对方地址：搜索失败时，贴入对方显示的完整地址。
- 连接、断开：申请连接或停止所选连接。自动发现不会自动接受控制。

| 方向 | 确认后怎样使用 |
| --- | --- |
| 我控制对方 | 本机选择对方窗口，由本机主窗口发出操作。 |
| 对方控制我 | 对方选择本机窗口，由对方主窗口发出操作。 |
| 双向 | 两边都能选择和控制对方窗口。尽量每次只由一边操作，避免互相覆盖。 |

接收端看设备名和请求方向后选择接受或拒绝。未接受、已拒绝或断开后，控制消息不应用。改变方向需重新连接并确认。可以同时选择多个远程窗口或多台电脑，无需添加本机跟随窗口。

网络变化后地址和设备列表自动更新。程序重启会重新分配端口，不自动恢复控制授权；必要时重新复制地址并连接。中断时显示状态，重新连接后请检查原有选择。

分组中的 `ms` 是网络往返时间，不是画面误差或精确单向延迟。远程按操作事件和绝对时间同步，不强求本机 100 毫秒标准；网络、解码和机器性能都会影响画面差异。

## 4. 遇到问题

| 现象 | 处理 |
| --- | --- |
| 没有本机窗口 | 先在 PotPlayer 打开视频，再刷新。需允许多个实例，程序与播放器处于同一桌面、相同权限级别。 |
| 跟随不能勾选 | 本机窗口需打开本地同步；远程窗口需连接、对方接受且方向允许本机控制。双击远程行可打开连接区域。 |
| 搜索不到电脑 | 使用复制地址方式。同一 Wi-Fi 的访客网络或设备隔离可能禁止互访。 |
| 没有本机地址 | 检查网线或 Wi-Fi，恢复网络后自动刷新，无需配置端口。 |
| 等待确认后失败 | 对方需打开 SyncPlayer 并接受。重新复制当前地址，检查局域网。 |
| 防火墙提示 | 在信任的局域网允许 SyncPlayer 使用专用网络，不要关闭整个防火墙。手动连接也需要消息可达。 |
| 多个 IP | 选与对方同局域网的地址。先试第一项，失败再试其他。 |
| 画面仍不对应 | 检查内容、时间轴，用偏移补偿剪辑起点差。不同长度视频无法全程对应。 |
| 窗口关闭或无响应 | 列表自动刷新；重新打开视频并检查主窗口和跟随项。窗口失败不会使界面一直等待。 |
| 偏移无法提交 | 范围 `-86400` 至 `86400` 秒，可带小数，删除非数字字符。 |

SyncPlayer 不传输视频，各电脑提前准备文件。跨地点公网连接不属于自动发现功能范围。

## 5. 源码、构建与验证

发布包包含独立 Windows x64 EXE 和三语说明书；说明书应与 EXE 放在一起。首次启动默认英语、本地同步开启、远程连接关闭。已有语言和设备名称保存在当前 Windows 用户的设置中，更新版本不会主动重置。

源码构建需要 .NET 10 SDK，运行 `powershell -ExecutionPolicy Bypass -File scripts/build.ps1`。`Start.cmd` 打开本地构建或发布版；`scripts/package.ps1` 在 `artifacts` 生成独立发布包和 SHA-256 校验文件，需要时从微软官方 NuGet 源下载运行环境。

| 目录 | 职责 |
| --- | --- |
| `src/UI` | 界面、窗口表、设置和同步操作组织。 |
| `src/Playback` | PotPlayer 接口、跳转识别、调速校准和偏移边界。 |
| `src/Network` | 局域网发现、授权、多设备连接、延迟和协议。 |
| `src/Configuration` | 语言、设备身份及保存的设置。 |
| `tests` | 验证代码，不编入正式 EXE。 |
| `scripts` | 构建、测试、打包入口。 |

`scripts/test.ps1` 检查协议、发现及语言；加 `-Video` 使用 `test-video` 中的本地视频操作两个真实 PotPlayer 窗口，加 `-Screenshots` 生成界面预览。结果保存在 `diagnostics`，结束时尝试恢复播放器位置、状态、速度和静音。需要 SDK 和诊断构建；发布 EXE 不包含这些测试入口。

真实视频已检查播放暂停、绝对跳转和回退、重复对齐、变速且不周期性补跳、静音、空偏移归零、头尾停住及自动恢复。时间差依据播放器读数，不是逐帧画面比较。开发环境限制了实体按键激活，相应测试使用 PotPlayer 按键接口和绝对定位。

同机三个服务实例已检查同时连接、多设备延迟、独立控制和断开、接受拒绝、手动连接及端口占用；自动发现经过实际网卡。多网卡排序、无网络数据及地址变化使用模拟数据。两台实体电脑、真实网卡断开、路由器隔离和防火墙提示尚未实测。
