# SyncPlayer 使用说明

同步两台 Windows 电脑上的 PotPlayer。同一时刻只有一方能控制另一方，可以申请交换主控。两端各自打开视频；中转不传输视频、屏幕、键盘或鼠标操作。

## 本地同步

在同一台电脑打开多个 PotPlayer 视频窗口，选择一个「主窗口」，再勾选其他窗口的「同步」。「本地同步」默认开启，无需联网；播放、暂停和跳转会跟随主窗口，也可设置偏移和静音。「本地同步｜远程同步」始终只选一项，默认本地。切换到远程时隐藏其他本机窗口，切回后恢复原选择。

## 远程连接

1. 两端运行 `SyncPlayer.exe`，各自在 PotPlayer 打开视频，并在「主窗口」选择作为同步基准的视频窗口。
2. 选择主窗口下方的「远程同步」。本地同步与远程连接互斥；打开本地同步会断开远程连接。首次远程连接前，请填写程序旁 relay.json 中的 server，方法见后面的「设置中转」。
3. 主控点击「发起」，再点击「复制连接码」。连接码10分钟内可首次加入，一次连接最长有效8小时。
4. 受控方将连接码粘贴到「主控连接码」，点击「加入」。主控在申请列表选中一人，再点击「接受」；列表最多显示3行，超过可滚动。连接后显示对方名称、双方权限和往返延迟，其余申请结束。
5. 远程同步只控制双方选定的主窗口。两端视频准备好后自动同步，连接后才打开视频也会自动同步。未准备好时会提示打开视频。受控端控制按钮置灰，主控可使用播放／暂停、同步、跳转、偏移和静音控件。短暂断网显示「正在重连」，保留当前主控，恢复后重新测量往返。
6. 点击「断开」或选择「本地同步」，结束本端连接。

## 交换主控

受控方点击「接管」，当前主控点击「接受」或「拒绝」。申请30秒内有效。接受后交换权限，并同步新主控当前播放状态。之后可用相同步骤申请换回。

## 延迟说明

本地同步无需经过网络，但播放器处理指令、跳转解码和音频缓冲仍可能让不同窗口出现短暂的播放差异。

远程同步还受网络和中转服务影响，两台电脑可能出现可察觉的音画不同步。偏移可用于微调相对播放位置，但不能消除不断变化的网络延迟。

连接信息中的「往返」测量本机经中转到对方、再经中转返回的时间，每2秒测量一次，显示最近5次成功测量的中位数。「—」表示尚无测量值或6秒内未收到回复，断线后会清空；两端均需使用此版本。它包含传输和回复处理时间，不等于单向指令延迟，也不包含视频解码、音频缓冲和显示耗时，不能直接代表两端的实际音画差异。

## 设置中转

首次远程连接前，用记事本打开 `SyncPlayer.exe` 旁的 `relay.json`，将 `server` 的值替换为新服务的 HTTPS 根网址，保留 JSON 的引号和大括号。两台电脑须使用相同的中转服务。此文件需与程序放在一起，修改后在下一次发起或加入连接时生效。
