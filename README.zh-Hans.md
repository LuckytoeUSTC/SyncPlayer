# SyncPlayer

[English](README.md) · 简体中文 · [繁體中文](README.zh-Hant.md)

在一台 Windows 电脑或局域网内同步多个 PotPlayer 窗口，跟随绝对位置、播放状态和速度。每个窗口可设置偏移和静音，支持自动发现设备、连接确认和延迟显示。

**[下载 Windows x64 版本](https://github.com/LuckytoeUSTC/SyncPlayer/releases/latest)**：解压 ZIP，双击 `SyncPlayer.exe`。不需要另装 .NET；PotPlayer 需自行安装，视频需放在各台电脑上。

## 0. 快速入门

首次启动默认英语。点击右上角齿轮，直接选择 **简体中文** 切换语言，立即生效并自动保存。问号图标打开当前语言的使用说明。

### 0.0 同一台电脑

1. 在 PotPlayer 中打开视频，多个视频分别在不同窗口打开。
2. 双击 `SyncPlayer.exe`。
3. 在顶部选择“主窗口”。
4. 主窗口下方的“本地同步”开关默认打开。在表格勾选需要“跟随”的其它本机窗口。
5. 在主窗口播放、暂停、跳转或调速。需要重新校准时点“同步”。

只保留一个声音时，在其他窗口所在行勾选“静音”。视频起点有差别时，填写该行的“偏移(秒)”。

### 0.1 两台电脑

1. 两台电脑连接同一个局域网，各自在 PotPlayer 中打开视频。
2. 两台电脑分别双击 `SyncPlayer.exe`。
3. 分别在顶部选择各自的“主窗口”。
4. 两端都打开主窗口下方的“远程连接”开关。“本地同步”会自动关闭；如果本机其它窗口也需要同步，手动重新打开“本地同步”即可。
5. 控制端选另一台电脑，选择“我控制对方”，点“连接”。
6. 另一台电脑看到请求后点“接受”。
7. 控制端在窗口表中勾选对方电脑下面的视频窗口，然后操作控制端主窗口。

搜索不到时，在另一台电脑点“复制地址”，贴到控制端的“对方地址”，再点“连接”。本机地址有多个时，不一定每个都能连接另一台电脑；一般先用列表第一项，失败再选择与对方处于同一网络的其它地址重新复制。无需查 IP 或填写端口。

## 1. 窗口表怎样使用

先列本机窗口，再按设备名称列远程窗口。主窗口始终是来源，不显示跟随复选框。名称以视频文件名为准，不显示播放器后缀；同一设备上的文件名相同时才加序号。长名称换行，悬停可看完整名称。新增、关闭和更换视频后自动刷新，也可以点击顶部环形箭头刷新。新发现的本机窗口默认不勾选。

| 项目 | 操作 |
| --- | --- |
| 主窗口 | 顶部选择操作来源。本机跟随窗口可以一个也不选。 |
| 跟随 | 勾选需要同步的窗口。本地同步关闭时隐藏本机其它窗口并停止操作，开启后恢复原选择。远程窗口需开启远程连接、获准连接且方向允许本机控制。 |
| 偏移(秒) | 留空或只输入空格会自动变为 `0`。可填正数、负数、小数，例如 `0.25`、`-1.5`。主窗口也可设置偏移。回车或点击其它位置提交，左右箭头每次调整 0.1 秒。 |
| 静音 | 只关闭这一窗口的声音，取消勾选恢复声音。与是否跟随无关；静音主窗口不影响其他窗口。 |
| 状态 | 显示窗口角色或连接状态。远程分组行还显示网络往返延迟。 |

偏移表示“此窗口位置 = 主窗口位置 + 此窗口偏移 − 主窗口偏移”。同一画面在主视频第 10 秒、另一视频第 12 秒出现，就给另一视频填 `2`；填 `-2` 则让它位于主窗口之前 2 秒。修改已勾选窗口的偏移会同步；未勾选时仅保存本次设置。目标位置越过片头时停在第一帧等待；越过片尾时暂停在片尾附近的可定位画面，避免播放器自动重播或进入下一项。重新进入有效范围后自动恢复同步，回退或修改偏移也能恢复。跟随窗口在片头或片尾等待时，主窗口可以继续播放。

修改主窗口偏移，会按偏移变化量移动主窗口；目标未越过视频边界时，其它窗口保持原位置。位置受视频头尾限制。下方跳转输入框的左右箭头同样每次调整 0.1 秒。
远程偏移和静音由有控制权的一端修改。播放器中的静音变化会随状态更新。偏移和跟随选择不跨程序重启保存。

## 2. 播放与跳转

| 控件 | 用途 |
| --- | --- |
| 三角形／双竖线按钮 | 同一个按钮随主窗口状态切换：三角形表示开始播放，双竖线表示暂停。操作主窗口、选中的本机窗口及有控制权的远程窗口。重复暂停不会切换为播放。 |
| 同步 | 按主窗口当前绝对时间、速度和状态重新同步，保留各窗口偏移。 |
| 取消偏移 | 位于“同步”右侧，将主窗口、其它本机窗口及远程窗口的偏移全部设为零，并同步当前选中的跟随窗口。未勾选的窗口只清零设置，不改变播放位置。 |
| 本地同步开关 | 位于主窗口下方。默认开启；关闭后本机其它窗口从列表消失，停止向它们发送播放、同步或跳转操作，选择保留。远程同步独立。 |
| 跳转 | 在独立区域输入从视频开始计算的秒数，例如 `90.5`，再点“跳转”。 |
| 问号图标 | 打开当前语言的使用说明。图标悬停显示用途。 |
| 齿轮图标（设置） | 齿轮下方显示 English、简体中文、繁體中文，点选立即切换并自动保存，无需确认。设备名称、窗口选择和同步不因语言切换重置。 |

照常在主窗口使用左右键、Ctrl 加左右键、点击进度条或 X/C 调速，勾选的跟随窗口会同步跳转和速度。操作跟随窗口不会改变主窗口。

本机视频跳转时可能短暂停顿，定位后一起恢复播放。视频解码和电脑负载会影响画面是否一致；看到差异时可以点“同步”。

首次同步时，播放器准备过程中画面可能短暂变化。退出时正常关闭 SyncPlayer，让它恢复临时调整过的播放器选项。

## 3. 连接设备

“远程连接”是主窗口下方、位于“本地同步”旁边的开关。打开时显示连接区域，并自动关闭本地同步；关闭时断开设备、停止远程控制、隐藏远程窗口，并自动打开本地同步。自动配置只发生在远程连接开关改变时；远程连接保持打开期间，可以手动打开本地同步，程序不会再替你关闭。连接前两台电脑都需打开远程连接。启动时仅本地同步打开。

- 本机名称：直接修改，按回车或移开焦点保存。默认形如 `PC-7K3M2Q`，根据本机信息生成，通常每台电脑不同。自定义名称保存在当前用户设置中。同名设备加四位短标识，用这个短标识区分同名设备。
- 本机地址：自动获取 IP 并分配端口。“复制地址”复制选中的完整地址。多个地址不一定都能连接另一台电脑，一般先用列表第一项；失败再选择与对方处于同一网络的其它地址。有网关的地址优先。网络变化后自动更新，并每约 2 秒检查一次；换网络或路由器重新分配时 IP 可能变化，重启程序后端口可能变化，请复制当前地址。
- 设备列表：自动搜索同一局域网中的 SyncPlayer，逐台显示名称、连接标记及往返延迟。选中后点连接。可同时连接多台，选择另一台不会断开已有连接；断开按钮只作用于当前选中的设备。
- 对方地址：搜索失败时，贴入对方显示的完整地址。
- 连接、断开：申请连接或停止所选连接。自动发现不会自动接受控制。

| 方向 | 确认后怎样使用 |
| --- | --- |
| 我控制对方 | 本机选择对方窗口，由本机主窗口发出操作。 |
| 对方控制我 | 对方选择本机窗口，由对方主窗口发出操作。 |
| 双向 | 两边都能选择和控制对方窗口。尽量每次只由一边操作，避免互相覆盖。 |

接收端看设备名和请求方向后选择接受或拒绝。未接受、已拒绝或断开后，不能控制对方。改变方向需重新连接并确认。可以同时选择多个远程窗口或多台电脑，无需添加本机跟随窗口。

网络变化后地址和设备列表自动更新。程序重启会重新分配端口，不自动恢复控制授权；必要时重新复制地址并连接。中断时显示状态，重新连接后请检查原有选择。

设备旁的 `ms` 表示网络响应快慢，不是视频画面之间的时间差。跨电脑播放的画面差异可能超过 0.1 秒，网络状况、视频解码和电脑负载都会影响结果，程序无法始终将它控制在 0.1 秒以内。看到差异时可以点“同步”；使用网线、减少电脑上同时运行的高负载任务可能有帮助。

## 4. 遇到问题

| 现象 | 处理 |
| --- | --- |
| 没有本机窗口 | 先在 PotPlayer 打开视频，再刷新。需允许多个实例，程序与播放器处于同一桌面、相同权限级别。 |
| 跟随不能勾选 | 本机窗口需打开本地同步；远程窗口需连接、对方接受且方向允许本机控制。双击远程行可打开连接区域。 |
| 搜索不到电脑 | 使用复制地址方式。同一 Wi-Fi 的访客网络或设备隔离可能禁止互访。 |
| 没有本机地址 | 检查网线或 Wi-Fi，恢复网络后自动刷新，无需配置端口。 |
| 等待确认后失败 | 对方需打开 SyncPlayer 并接受。重新复制当前地址，检查局域网。 |
| 防火墙提示 | 在信任的局域网允许 SyncPlayer 使用专用网络，不要关闭整个防火墙。手动连接也需要消息可达。 |
| 多个 IP | 选与对方同局域网的地址。先试第一项，失败再试其他。 |
| 画面仍不对应 | 检查内容、时间轴，用偏移补偿剪辑起点差。不同长度视频无法全程对应。 |
| 窗口关闭或无响应 | 列表自动刷新；重新打开视频并检查主窗口和跟随项。窗口失败不会使界面一直等待。 |
| 偏移无法提交 | 范围 `-86400` 至 `86400` 秒，可带小数，删除非数字字符。 |

SyncPlayer 不传输视频，各电脑提前准备文件。跨地点公网连接不属于自动发现功能范围。

## 5. 安装与更新

发布页提供两个 ZIP：普通包不含视频，文件名带 with-videos 的包在 test-video 文件夹中附带两份参考视频。分别用两个 PotPlayer 窗口打开它们，即可体验本地同步。视频是独立文件，不编入 EXE，也不属于 SyncPlayer 的 MIT 授权范围。

下载最新版 Windows x64 ZIP 并解压，保留 EXE、三语使用说明、LICENSE 和 NOTICE.md 在同一文件夹。PotPlayer 需单独安装，各台电脑需提前放好视频，SyncPlayer 不会把视频传到其它电脑。

更新时先关闭 SyncPlayer，将新版 ZIP 解压到新文件夹，再双击其中的 `SyncPlayer.exe`。原来的语言和设备名称会保留。重新打开后请检查主窗口、跟随项及偏移；跟随选择、偏移和远程连接不会跨程序重启保留。
