# SyncPlayer

[English](README.md) · [简体中文](README.zh-Hans.md) · 繁體中文

在一台 Windows 電腦或區域網路內同步多個 PotPlayer 視窗，跟隨絕對位置、播放狀態與速度。各視窗可設定偏移與靜音，支援自動探索裝置、連線確認與延遲顯示。

**[下載 Windows x64 版本](https://github.com/LuckytoeUSTC/SyncPlayer/releases/latest)**：解壓縮 ZIP，執行 `SyncPlayer.exe`。不需要另外安裝 .NET；PotPlayer 請自行安裝，影片需放在各台電腦上。

## 0. 快速入門

首次啟動默認英語。點擊右上角齒輪，直接選擇 **繁體中文** 切換語言，立即生效并自動儲存。問號圖標打開當前語言的說明書。

### 0.0 同一臺電腦

1. 在 PotPlayer 中打開影片，多個影片分別在不同視窗打開。
2. 執行 `SyncPlayer.exe`，選擇主視窗。
3. 打開主視窗下方的“本機同步”開關，在表格勾選需要“跟隨”的視窗。
4. 在主視窗播放、暫停、跳轉或調速。需要重新校準時點“對齊”。

只保留一個聲音時，在其他視窗所在行勾選“靜音”。影片起點有差別時，填寫該行的“偏移(秒)”。

### 0.1 兩臺電腦

1. 兩臺電腦各自打開影片及 SyncPlayer，連接同一個區域網路。
2. 兩端都開啟「遠端連線」，控制端選另一臺電腦，選擇“我控制對方”，點“連接”。
3. 另一臺電腦看到請求后點“接受”。
4. 控制端在視窗表中勾選對方電腦下面的影片視窗。
5. 操作控制端主視窗。只做跨電腦同步時，關閉「本機同步」即可。

搜索不到時，在另一臺電腦開啟「遠端連線」並點「複製位址」，貼到控制端的“對方位址”，再點“連接”。無需查 IP 或填寫連接埠。

## 1. 視窗表怎樣使用

先列本機視窗，再按裝置名稱列遠程視窗。主視窗始終是來源，不顯示跟隨核取方塊。名稱以影片文件名為準，不顯示播放器后綴；同一裝置上的文件名相同時才加序號。長名稱換行，懸停可看完整名稱。新增、關閉和更換影片后自動重新整理，也可以點擊頂部環形箭頭重新整理。新發現的本機視窗默認不勾選。

| 項目 | 操作 |
| --- | --- |
| 主視窗 | 頂部選擇操作來源。本機跟隨視窗可以一個也不選。 |
| 跟隨 | 勾選需要同步的視窗。本機同步關閉時隱藏本機其他視窗並停止操作，開啟後恢復原選擇。遠端視窗需開啟遠端連線、獲准連線且方向允許本機控制。 |
| 偏移(秒) | 留空或只輸入空格會自動變為 `0`。可填正數、負數、小數，例如 `0.25`、`-1.5`。主視窗是基準，其偏移不能編輯。 |
| 靜音 | 只關閉這一視窗的聲音，取消勾選恢復聲音。與是否跟隨無關；靜音主視窗不影響其他視窗。 |
| 狀態 | 顯示視窗角色或連接狀態。遠程分組行還顯示網路往返延遲。 |

偏移表示“此視窗位置 = 主視窗位置 + 偏移”。同一畫面在主影片第 10 秒、另一影片第 12 秒出現，就給另一影片填 `2`；填 `-2` 則讓它位于主視窗之前 2 秒。修改已勾選視窗的偏移會對齊；未勾選時僅儲存本次設定。目標位置越過片頭時停在第一幀等待；越過片尾時暫停在片尾附近的可定位畫面，避免播放器自動重播或進入下一項。重新進入有效范圍后自動恢復同步，回退或修改偏移也能恢復。片尾預留約 300 毫秒的解碼保護區；此時跟隨視窗暫停而主視窗繼續播放是有意的邊界行為。

遠程偏移和靜音由有控制權的一端修改。播放器中的靜音變化會隨狀態更新。偏移和跟隨選擇不跨程序重啟儲存。

## 2. 播放與跳轉

| 控件 | 用途 |
| --- | --- |
| 三角形／雙豎線按鈕 | 同一個按鈕隨主視窗狀態切換：三角形表示開始播放，雙豎線表示暫停。操作主視窗、選中的本機視窗及有控制權的遠程視窗。重復暫停不會切換為播放。 |
| 對齊 | 按主視窗當前絕對時間、速度和狀態重新對齊，保留各視窗偏移。 |
| 本機同步開關 | 位於主視窗下方，預設開啟。關閉後本機其他視窗從列表消失，停止向它們發送播放、對齊或跳轉操作，選擇保留。遠端同步獨立。 |
| 跳轉 | 在獨立區域輸入從影片開始計算的秒數，例如 `90.5`，再點“跳轉”。 |
| 問號圖標 | 打開當前語言的說明書。圖標懸停顯示用途。 |
| 齒輪圖標（設定） | 齒輪下方顯示 English、簡體中文、繁體中文，點選立即切換并自動儲存，無需確認。裝置名稱、視窗選擇和同步不因語言切換重置。 |

左右鍵、Ctrl 加左右鍵、進度條跳轉及 X/C 調速，按播放器實際產生的位置和倍率處理，不假定快捷鍵跳轉固定秒數。跟隨視窗中的操作不會反向改變主視窗。

同機跳轉會等待定位后恢復播放，解碼起步差在這次操作內通過短暫調速處理。正常播放不做週期性補跳；調速直接同步倍率，並在這次變速後按需短暫微調跟隨視窗的倍率，消除殘留時間差，不跳轉。本機目標約 100 毫秒，實際效果受解碼和機器負載影響。

初次同步會檢查精確跳轉，必要時臨時關閉“只跳到關鍵幀”。正常退出恢復程序修改過的選項。準備期間可能短暫改變畫面，隨后恢復并對齊；強制結束進程無法保證恢復。

## 3. 連接裝置

「遠端連線」開關與「本機同步」位於同一行，預設關閉。開啟後顯示連線區域；關閉後中斷遠端連線、停止遠端控制並隱藏遠端列。連線前兩台電腦都需開啟此開關。

- 本機名稱：直接修改，按回車或移開焦點儲存。默認形如 `PC-7K3M2Q`，根據本機信息生成，通常每臺電腦不同。自定義名稱儲存在當前用戶設定中。同名裝置加四位短標識，連接按內部身份區分。
- 本機位址：自動獲取 IP 并分配連接埠。“復制位址”復制選中的完整位址。多個網路介面卡列出多個位址，有網關的連接優先。
- 裝置列表：自動搜索同一區域網路中的 SyncPlayer，逐臺顯示名稱、連接標記及往返延遲。選中后點連接。可同時連接多臺，選擇另一臺不會斷開已有連接；斷開按鈕只作用于當前選中的裝置。
- 對方位址：搜索失敗時，貼入對方顯示的完整位址。
- 連接、斷開：申請連接或停止所選連接。自動發現不會自動接受控制。

| 方向 | 確認后怎樣使用 |
| --- | --- |
| 我控制對方 | 本機選擇對方視窗，由本機主視窗發出操作。 |
| 對方控制我 | 對方選擇本機視窗，由對方主視窗發出操作。 |
| 雙向 | 兩邊都能選擇和控制對方視窗。盡量每次只由一邊操作，避免互相覆蓋。 |

接收端看裝置名和請求方向后選擇接受或拒絕。未接受、已拒絕或斷開后，控制消息不應用。改變方向需重新連接并確認。可以同時選擇多個遠程視窗或多臺電腦，無需添加本機跟隨視窗。

網路變化后位址和裝置列表自動更新。程序重啟會重新分配連接埠，不自動恢復控制授權；必要時重新復制位址并連接。中斷時顯示狀態，重新連接后請檢查原有選擇。

分組中的 `ms` 是網路往返時間，不是畫面誤差或精確單向延遲。遠程按操作事件和絕對時間同步，不強求本機 100 毫秒標準；網路、解碼和機器性能都會影響畫面差異。

## 4. 遇到問題

| 現象 | 處理 |
| --- | --- |
| 沒有本機視窗 | 先在 PotPlayer 打開影片，再重新整理。需允許多個實例，程序與播放器處于同一桌面、相同權限級別。 |
| 跟隨不能勾選 | 本機視窗需打開本機同步；遠程視窗需連接、對方接受且方向允許本機控制。雙擊遠程行可打開連接區域。 |
| 搜索不到電腦 | 使用復制位址方式。同一 Wi-Fi 的訪客網路或裝置隔離可能禁止互訪。 |
| 沒有本機位址 | 檢查網線或 Wi-Fi，恢復網路后自動重新整理，無需配置連接埠。 |
| 等待確認后失敗 | 對方需打開 SyncPlayer 并接受。重新復制當前位址，檢查區域網路。 |
| 防火墻提示 | 在信任的區域網路允許 SyncPlayer 使用專用網路，不要關閉整個防火墻。手動連接也需要消息可達。 |
| 多個 IP | 選與對方同區域網路的位址。先試第一項，失敗再試其他。 |
| 畫面仍不對應 | 檢查內容、時間軸，用偏移補償剪輯起點差。不同長度影片無法全程對應。 |
| 視窗關閉或無響應 | 列表自動重新整理；重新打開影片并檢查主視窗和跟隨項。視窗失敗不會使界面一直等待。 |
| 偏移無法提交 | 范圍 `-86400` 至 `86400` 秒，可帶小數，刪除非數字字符。 |

SyncPlayer 不傳輸影片，各電腦提前準備文件。跨地點公網連接不屬于自動發現功能范圍。

## 5. 原始碼、建置與驗證

發行套件包含獨立 Windows x64 EXE 與三語說明書，請將說明書放在 EXE 旁。首次啟動預設英語、本機同步開啟、遠端連線關閉。既有語言與裝置名稱保存在目前 Windows 使用者的設定中，更新版本不會主動重設。

從原始碼建置需要 .NET 10 SDK，執行 `powershell -ExecutionPolicy Bypass -File scripts/build.ps1`。`Start.cmd` 開啟本機建置或發行版；`scripts/package.ps1` 在 `artifacts` 產生獨立套件與 SHA-256 校驗檔，需要時從微軟官方 NuGet 來源下載執行環境。

| 目錄 | 職責 |
| --- | --- |
| `src/UI` | 介面、視窗表、設定與同步操作組織。 |
| `src/Playback` | PotPlayer 介面、跳轉偵測、調速校準與偏移邊界。 |
| `src/Network` | 區域網路探索、授權、多裝置連線、延遲與協定。 |
| `src/Configuration` | 語言、裝置身分與儲存的設定。 |
| `tests` | 驗證程式碼，不編入正式 EXE。 |
| `scripts` | 建置、測試與打包入口。 |

`scripts/test.ps1` 檢查協定、探索與語言；加 `-Video` 使用 `test-video` 中的本機影片操作兩個真實 PotPlayer 視窗，加 `-Screenshots` 產生介面預覽。結果保存在 `diagnostics`，結束時嘗試還原播放器的位置、狀態、速度與靜音。需要 SDK 與診斷建置；發行 EXE 不包含這些測試入口。

真實影片已檢查播放暫停、絕對跳轉與倒退、重複對齊、變速且不週期性補跳、靜音、空偏移歸零、頭尾停住與自動恢復。時間差依據播放器讀數，並非逐格畫面比較。開發環境限制了實體按鍵啟用，相關測試使用 PotPlayer 按鍵介面與絕對定位。

同機三個服務實例已檢查同時連線、多裝置延遲、獨立控制與斷線、接受拒絕、手動連線與連接埠占用；自動探索經過實際網路介面卡。多網卡排序、無網路資料與位址變化使用模擬資料。兩台實體電腦、真實網卡斷線、路由器隔離與防火牆提示尚未實測。
