# SyncPlayer 使用說明

同步兩台 Windows 電腦上的 PotPlayer。同一時刻只有一方能控制另一方，可以申請交換主控。兩端各自開啟影片；中轉不傳輸影片、螢幕、鍵盤或滑鼠操作。

## 本機同步

在同一台電腦開啟多個 PotPlayer 影片視窗，選擇一個「主視窗」，再勾選其他視窗的「同步」。「本機同步」預設開啟，無需連網；播放、暫停和跳轉會跟隨主視窗，也可設定偏移和靜音。「本機同步｜遠端同步」始終只選一項，預設本機。切換到遠端時隱藏其他本機視窗，切回後恢復原選擇。

## 遠端連線

1. 兩端執行 `SyncPlayer.exe`，各自在 PotPlayer 開啟影片，並在「主視窗」選擇作為同步基準的影片視窗。
2. 選擇主視窗下方的「遠端同步」。本機同步與遠端連線互斥；開啟本機同步會中斷遠端連線。首次遠端連線前，請填寫程式旁 relay.json 中的 server，方法見後面的「設定中轉」。
3. 主控點擊「發起」，再點擊「複製連線碼」。連線碼10分鐘內可首次加入，一次連線最長有效8小時。
4. 受控方將連線碼貼入「主控連線碼」，點擊「加入」。主控在申請清單選取一人，再點擊「接受」；清單最多顯示3行，超過可捲動。連線後顯示對方名稱、雙方權限和往返延遲，其餘申請結束。
5. 遠端同步只控制雙方選定的主視窗。兩端影片準備好後自動同步，連線後才開啟影片也會自動同步。未準備好時會提示開啟影片。受控端控制按鈕反灰，主控可使用播放／暫停、同步、跳轉、偏移和靜音控件。短暫斷網顯示「正在重新連線」，保留目前主控，恢復後重新測量往返。
6. 點擊「中斷連線」或選擇「本機同步」，結束本端連線。

## 交換主控

受控方點擊「接管」，目前主控點擊「接受」或「拒絕」。申請30秒內有效。接受後交換權限，並同步新主控目前的播放狀態。之後可用相同步驟申請換回。

## 延遲說明

本機同步無需經過網路，但播放器處理指令、跳轉解碼和音訊緩衝仍可能讓不同視窗出現短暫的播放差異。

遠端同步還受網路和中轉服務影響，兩台電腦可能出現可察覺的影音不同步。偏移可用於微調相對播放位置，但不能消除不斷變動的網路延遲。

連線資訊中的「往返」測量本機經中轉到對方、再經中轉返回的時間，每2秒測量一次，顯示最近5次成功測量的中位數。「—」表示尚無測量值或6秒內未收到回覆，斷線後會清空；兩端均需使用此版本。它包含傳輸和回覆處理時間，不等於單向指令延遲，也不包含影片解碼、音訊緩衝和顯示耗時，不能直接代表兩端的實際影音差異。

## 設定中轉

首次遠端連線前，用記事本開啟 `SyncPlayer.exe` 旁的 `relay.json`，將 `server` 的值替換為新服務的 HTTPS 根網址，保留 JSON 的引號和大括號。兩台電腦須使用相同的中轉服務。此檔案需與程式放在一起，修改後在下一次發起或加入連線時生效。
