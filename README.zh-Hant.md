# SyncPlayer

[English](README.md) · [简体中文](README.zh-Hans.md) · 繁體中文

在一台 Windows 電腦或區域網路內同步多個 PotPlayer 視窗，跟隨絕對位置、播放狀態與速度。各視窗可設定偏移與靜音，支援自動探索裝置、連線確認與延遲顯示。

**[下載 Windows x64 版本](https://github.com/LuckytoeUSTC/SyncPlayer/releases/latest)**：解壓縮 ZIP，執行 `SyncPlayer.exe`。不需要另外安裝 .NET；PotPlayer 請自行安裝，影片需放在各台電腦上。

## 0. 快速入門

首次啟動預設為英語。點擊右上角齒輪，直接選擇 **繁體中文** 切換語言，立即生效並自動儲存。問號圖標打開目前語言的使用說明。

### 0.0 同一臺電腦

1. 在 PotPlayer 中打開影片，多個影片分別在不同視窗打開。
2. 雙擊 `SyncPlayer.exe`。
3. 在頂部選擇「主視窗」。
4. 主視窗下方的「本機同步」開關預設開啟。在表格勾選需要「跟隨」的其他本機視窗。
5. 在主視窗播放、暫停、跳轉或調速。需要重新校準時點「同步」。

只保留一個聲音時，在其他視窗所在行勾選「靜音」。影片起點有差別時，填寫該行的「偏移(秒)」。

### 0.1 兩臺電腦

1. 兩臺電腦連線同一個區域網路，各自在 PotPlayer 中打開影片。
2. 兩臺電腦分別雙擊 `SyncPlayer.exe`。
3. 分別在頂部選擇各自的「主視窗」。
4. 兩端都開啟主視窗下方的「遠端連線」開關。「本機同步」會自動關閉；如果本機其他視窗也需要同步，手動重新開啟「本機同步」即可。
5. 控制端選另一臺電腦，選擇「我控制對方」，點「連線」。
6. 另一臺電腦看到請求後點「接受」。
7. 控制端在視窗表中勾選對方電腦下面的影片視窗，然後操作控制端主視窗。

搜尋不到時，在另一臺電腦點「複製位址」，貼到控制端的「對方位址」，再點「連線」。本機位址有多個時，不一定每個都能連線另一臺電腦；一般先用清單第一項，失敗再選擇與對方處於同一網路的其他位址重新複製。無需查 IP 或填寫連接埠。

## 1. 視窗表怎樣使用

先列本機視窗，再按裝置名稱列遠端視窗。主視窗始終是來源，不顯示跟隨核取方塊。名稱以影片檔名為準，不顯示播放器後綴；同一裝置上的檔名相同時才加序號。長名稱換行，懸停可看完整名稱。新增、關閉和更換影片後自動重新整理，也可以點擊頂部環形箭頭重新整理。新發現的本機視窗預設不勾選。

| 項目 | 操作 |
| --- | --- |
| 主視窗 | 頂部選擇操作來源。本機跟隨視窗可以一個也不選。 |
| 跟隨 | 勾選需要同步的視窗。本機同步關閉時隱藏本機其他視窗並停止操作，開啟後恢復原選擇。遠端視窗需開啟遠端連線、獲准連線且方向允許本機控制。 |
| 偏移(秒) | 留空或只輸入空格會自動變為 `0`。可填正數、負數、小數，例如 `0.25`、`-1.5`。主視窗也可設定偏移。按 Enter 或點擊其他位置提交，左右箭頭每次調整 0.1 秒。 |
| 靜音 | 只關閉這一視窗的聲音，取消勾選恢復聲音。與是否跟隨無關；靜音主視窗不影響其他視窗。 |
| 狀態 | 顯示視窗角色或連線狀態。遠端分組行還顯示網路往返延遲。 |

偏移表示“此視窗位置 = 主視窗位置 + 此視窗偏移 − 主視窗偏移”。同一畫面在主影片第 10 秒、另一影片第 12 秒出現，就給另一影片填 `2`；填 `-2` 則讓它位於主視窗之前 2 秒。修改已勾選視窗的偏移會同步；未勾選時僅儲存本次設定。目標位置越過片頭時停在第一幀等待；越過片尾時暫停在片尾附近的可定位畫面，避免播放器自動重播或進入下一項。重新進入有效範圍後自動恢復同步，回退或修改偏移也能恢復。跟隨視窗在片頭或片尾等待時，主視窗可以繼續播放。

修改主視窗偏移，會按偏移變化量移動主視窗；目標未越過影片邊界時，其他視窗保持原位置。位置受影片頭尾限制。下方跳轉輸入框的左右箭頭同樣每次調整 0.1 秒。
遠端偏移和靜音由有控制權的一端修改。播放器中的靜音變化會隨狀態更新。偏移和跟隨選擇不跨程式重啟儲存。

## 2. 播放與跳轉

| 控制項 | 用途 |
| --- | --- |
| 三角形／雙豎線按鈕 | 同一個按鈕隨主視窗狀態切換：三角形表示開始播放，雙豎線表示暫停。操作主視窗、選中的本機視窗及有控制權的遠端視窗。重複暫停不會切換為播放。 |
| 同步 | 按主視窗目前絕對時間、速度和狀態重新同步，保留各視窗偏移。 |
| 取消偏移 | 位於「同步」右側，將主視窗、其他本機視窗及遠端視窗的偏移全部設為零，並同步目前選中的跟隨視窗。未勾選的視窗只清零設定，不改變播放位置。 |
| 本機同步開關 | 位於主視窗下方，預設開啟。關閉後本機其他視窗從清單消失，停止向它們發送播放、同步或跳轉操作，選擇保留。遠端同步獨立。 |
| 跳轉 | 在獨立區域輸入從影片開始計算的秒數，例如 `90.5`，再點“跳轉”。 |
| 問號圖標 | 打開目前語言的使用說明。圖標懸停顯示用途。 |
| 齒輪圖標（設定） | 齒輪下方顯示 English、簡體中文、繁體中文，點選立即切換並自動儲存，無需確認。裝置名稱、視窗選擇和同步不因語言切換重置。 |

照常在主視窗使用左右鍵、Ctrl 加左右鍵、點擊進度條或 X/C 調速，勾選的跟隨視窗會同步跳轉和速度。操作跟隨視窗不會改變主視窗。

本機影片跳轉時可能短暫停頓，定位後一起恢復播放。影片解碼和電腦負載會影響畫面是否一致；看到差異時可以點「同步」。

首次同步時，播放器準備過程中畫面可能短暫變化。退出時正常關閉 SyncPlayer，讓它恢復臨時調整過的播放器選項。

## 3. 連線裝置

「遠端連線」是主視窗下方、位於「本機同步」旁邊的開關。開啟時顯示連線區域，並自動關閉本機同步；關閉時中斷裝置、停止遠端控制、隱藏遠端視窗，並自動開啟本機同步。自動配置只發生在遠端連線開關改變時；遠端連線保持開啟期間，可以手動開啟本機同步，程式不會再替你關閉。連線前兩台電腦都需開啟遠端連線。啟動時僅本機同步開啟。

- 本機名稱：直接修改，按Enter或移開焦點儲存。預設形如 `PC-7K3M2Q`，根據本機資訊生成，通常每臺電腦不同。自定義名稱儲存在目前使用者設定中。同名裝置加四位短標識，用這個短標識區分同名裝置。
- 本機位址：自動獲取 IP 並分配連接埠。「複製位址」複製選中的完整位址。多個位址不一定都能連線另一臺電腦，一般先用清單第一項；失敗再選擇與對方處於同一網路的其他位址。有閘道的位址優先。網路變化後自動更新，並每約 2 秒檢查一次；換網路或路由器重新分配時 IP 可能變化，重新啟動程式後連接埠可能變化，請複製目前位址。
- 裝置清單：自動搜索同一區域網路中的 SyncPlayer，逐臺顯示名稱、連線標記及往返延遲。選中後點連線。可同時連線多臺，選擇另一臺不會斷開已有連線；「中斷連線」按鈕只作用於目前選中的裝置。
- 對方位址：搜索失敗時，貼入對方顯示的完整位址。
- 連線、中斷連線：申請連線或停止所選連線。自動發現不會自動接受控制。

| 方向 | 確認後怎樣使用 |
| --- | --- |
| 我控制對方 | 本機選擇對方視窗，由本機主視窗發出操作。 |
| 對方控制我 | 對方選擇本機視窗，由對方主視窗發出操作。 |
| 雙向 | 兩邊都能選擇和控制對方視窗。盡量每次只由一邊操作，避免互相覆蓋。 |

接收端看裝置名和請求方向後選擇接受或拒絕。未接受、已拒絕或斷開後，不能控制對方。改變方向需重新連線並確認。可以同時選擇多個遠端視窗或多臺電腦，無需添加本機跟隨視窗。

網路變化後位址和裝置清單自動更新。程式重啟會重新分配連接埠，不自動恢復控制授權；必要時重新複製位址並連線。中斷時顯示狀態，重新連線後請檢查原有選擇。

裝置旁的 `ms` 表示網路回應快慢，不是影片畫面之間的時間差。跨電腦播放的畫面差異可能超過 0.1 秒，網路狀況、影片解碼和電腦負載都會影響結果，程式無法始終將它控制在 0.1 秒以內。看到差異時可以點「同步」；使用網線、減少電腦上同時執行的高負載工作可能有幫助。

## 4. 遇到問題

| 現象 | 處理 |
| --- | --- |
| 沒有本機視窗 | 先在 PotPlayer 打開影片，再重新整理。需允許多個實例，程式與播放器處於同一桌面、相同權限級別。 |
| 跟隨不能勾選 | 本機視窗需打開本機同步；遠端視窗需連線、對方接受且方向允許本機控制。雙擊遠端行可打開連線區域。 |
| 搜索不到電腦 | 使用複製位址方式。同一 Wi-Fi 的訪客網路或裝置隔離可能禁止互訪。 |
| 沒有本機位址 | 檢查網線或 Wi-Fi，恢復網路後自動重新整理，無需配置連接埠。 |
| 等待確認後失敗 | 對方需打開 SyncPlayer 並接受。重新複製目前位址，檢查區域網路。 |
| 防火牆提示 | 在信任的區域網路允許 SyncPlayer 使用專用網路，不要關閉整個防火牆。手動連線也需要訊息可達。 |
| 多個 IP | 選與對方同區域網路的位址。先試第一項，失敗再試其他。 |
| 畫面仍不對應 | 檢查內容、時間軸，用偏移補償剪輯起點差。不同長度影片無法全程對應。 |
| 視窗關閉或沒有回應 | 清單自動重新整理；重新打開影片並檢查主視窗和跟隨項。視窗失敗不會使介面一直等待。 |
| 偏移無法提交 | 範圍 `-86400` 至 `86400` 秒，可帶小數，刪除非數字字元。 |

SyncPlayer 不傳輸影片，各電腦提前準備檔案。跨地點公網連線不屬於自動發現功能範圍。

## 5. 安裝與更新

發行頁提供兩個 ZIP：一般套件不含影片，檔名帶 with-videos 的套件在 test-video 資料夾中附帶兩份參考影片。分別用兩個 PotPlayer 視窗打開它們，即可體驗本機同步。影片是獨立檔案，不編入 EXE，也不屬於 SyncPlayer 的 MIT 授權範圍。

下載最新版 Windows x64 ZIP 並解壓縮，保留 EXE、三語使用說明、LICENSE 和 NOTICE.md 在同一資料夾。PotPlayer 需單獨安裝，各台電腦需提前放好影片，SyncPlayer 不會把影片傳到其他電腦。

更新時先關閉 SyncPlayer，將新版 ZIP 解壓縮到新資料夾，再雙擊其中的 `SyncPlayer.exe`。原來的語言和裝置名稱會保留。重新打開後請檢查主視窗、跟隨項及偏移；跟隨選擇、偏移和遠端連線不會跨程式重新啟動保留。
